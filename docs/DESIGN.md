# DESIGN DOCUMENT - AVOLICIUS

## Nama Proyek

AVOLICIUS - Sistem Informasi Manajemen Pemesanan Produk Berbasis Alpukat

## Deskripsi Aplikasi

AVOLICIUS adalah sistem informasi yang digunakan untuk mengelola pemesanan produk makanan dan minuman berbahan dasar alpukat. Sistem ini membantu pelanggan melakukan pemesanan secara online dan membantu admin mengelola produk, transaksi, serta data pelanggan.

## Tujuan Aplikasi

- Mempermudah proses pemesanan produk alpukat.
- Mempermudah pengelolaan produk dan transaksi.
- Menyediakan informasi produk secara online.
- Mendukung proses checkout yang lebih cepat dan terstruktur.

## Fitur Utama

### Admin

- Login Admin
- Manajemen Produk
- Manajemen Pesanan
- Monitoring Transaksi

### Pelanggan

- Melihat Daftar Produk
- Detail Produk
- Keranjang Belanja
- Checkout Online
